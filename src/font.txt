# Crypts of Vael font: 16x8 characters, one bit per pixel.
# Each character: a line "= NAME" (the character itself, or SPACE, BULLET, CURSOR or BAR),
# then 8 rows of 16 marks, # = lit, . = unlit.
# Composite rule (checked by tools/font2asm.py): in every row, each run of lit pixels must be at
# least 2 pixels wide. A single unlit pixel between two runs is allowed.
# Codes: $20-$5F are ASCII. BULLET = $60, CURSOR = $61, BAR (the | character) = $62.
# Missing characters (e.g. @) draw as blanks.
