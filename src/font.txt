# Crypts of Vael font: 8x8 characters, one bit per pixel.
# Each character: a line "= NAME" (the character itself, or SPACE, BULLET, CURSOR or BAR),
# then 8 rows of 8 marks, # = lit, . = unlit.
# Codes: $20-$5F are ASCII. BULLET = $60, CURSOR = $61, BAR (the | character) = $62,
# HEARTL/HEARTR = $63/$64 (the heart, beating), HEART2L/HEART2R = $65/$66 (between beats).
# Missing characters (e.g. @) draw as blanks.
